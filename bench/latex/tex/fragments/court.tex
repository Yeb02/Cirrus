Le principe de longueur de description minimale énonce que le meilleur modèle génératif d'un jeu de
données est celui qui le compresse le plus. Pour une suite $x_1, \dots, x_n$, on compare
$L(M) + L(x \mid M)$ entre modèles.

Une suite aléatoire ne se compresse pas : sa longueur de description reste proche de $n \log_2 |\Sigma|$,
et la somme $\sum_{i=1}^{n} \ell(x_i)$ ne descend pas sous l'entropie.
